# Ejercicio 02 - Tarjeta de bienvenida

## Qué he aprendido
- A aplicar el Box Model en React Native diferenciando `padding` y `margin`.
- A redondear esquinas de contenedores usando `borderRadius`.
- A construir componentes visuales anidados (tarjeta y botón) usando `View`.

## Respuesta a la pregunta de comprensión
¿Por qué usarías `padding` en una tarjeta en lugar de `margin` para separar el texto del borde?

Respuesta:
Porque el `padding` genera espacio hacia adentro, empujando los elementos hijos respecto al límite interior de la tarjeta manteniendo el fondo del contenedor. En cambio, `margin` empujaría hacia afuera, separando la tarjeta entera de los elementos o bordes externos.

## Qué he modificado

## Resultado
Una tarjeta centrada con diseño oscuro, esquinas redondeadas y suficiente separación interior donde destacan el título, el subtítulo y el botón de acción centrado.
